# 概览

## 欢迎

**D3dxSkinManager** 是 **3DMigoto / XXMI** 模组的配套应用（原神、绝区零、星穹铁道、鸣潮、终末地，以及其他 XXMI 支持的游戏）。

它把你的模组放进一个压缩**库**，帮你**整理、预览、修复、编辑并部署**到 XXMI 的 `Mods` 文件夹——一键开启、一键关闭、一键启动。**游戏内注入与启动仍由 XXMI 完成；** 本应用是围绕它的库与工作台，让你少折腾文件、多做模组。

> [!TIP]
> **记住一条规则：** 同一分类**同时只有一个模组生效**。开启一个模组会自动关闭同分类里之前那个。

**如何阅读本文档：** **示例**是快速的分步演练，先从这里开始。需要细节时再看**功能**与**配置**。

---

# 示例

## 快速上手（第一次使用）

> [!GOAL]
> 从全新安装到第一个皮肤在游戏里生效。

1. 点击右上角的**配置文件选择器**，创建一个**配置文件**（每个游戏一个独立空间）。
2. 打开**设置 → 模组工作**，选择 **XXMI 启动器**。指向你的 XXMI 文件夹并选择所玩游戏的导入器（如绝区零选 `ZZMI`）。这会告诉应用把模组放到哪里**以及**如何启动游戏。
3. **添加模组：** 把模组的 `.zip` / `.7z` 文件（或其文件夹）拖到窗口上。
4. 打开**模组**标签页，**点击模组**即可开启。
5. 点击底部的**启动**按钮，带着已开启的模组进入游戏。

> [!TIP]
> 整个循环就是：**添加 → 开启 → 启动。** 其余功能都是为了更快、更整齐地完成它。

## 从网站获取模组

> [!GOAL]
> 从模组站点下载皮肤并使用——全程不用离开应用。

1. 打开**远程库**标签页 → **库管理（库管理）** → 添加一个库（选择一个**站点**和你的**游戏**）。应用会在后台获取列表。
2. **浏览或搜索**，点击你喜欢的模组。
3. 在模组页面点击某个**下载**按钮。
4. 确认弹窗（可以选择分类）。下载与安装在后台进行——在底部的**活动**区域查看。
5. 完成后模组会显示绿色 **✓**。像其他模组一样开启它，然后**启动**。

> [!NOTE]
> 有些站点（如夸克）需要先登录——见**配置 → 登录下载站点**。

## 游戏更新后模组坏了

> [!GOAL]
> 游戏更新后，让你的皮肤重新显示出来。

1. 打开**工具**标签页 → **分析**，查看哪些模组需要处理。
2. 右键被标记的模组 → **修复**（或一次修复整个分类）。
3. 在游戏内热重载——3DMigoto/XXMI 支持 **F10 热重载**——或重启游戏即可看到效果。

> [!NOTE]
> 通常**不需要**关闭游戏——3DMigoto 支持 F10 热重载模组。应用只是无法覆盖运行中的游戏当前**正打开**的文件；遇到这种情况它会先短暂重试，再报“正被占用”。此时重试即可，或关闭游戏（或在游戏内卸载该模组）让文件释放后再修复。

## 把两套外观合并成一个

> [!GOAL]
> 把同一角色的多个版本合并，用一个键在它们之间切换。

1. 在**模组**列表中，选中要合并的版本。
2. 点击**合并**并选择一个**切换键**。
3. 会生成一个新的合并模组（原始模组保留）。开启它，在游戏里按切换键循环外观。

# 功能

## 配置文件

**配置文件**是一个独立空间，拥有自己的模组、分类和设置。每个游戏建一个。在右上角的选择器切换或新建。

## 模组

**模组**标签页就是你的库——左侧分类，右侧模组。

- **开启 / 关闭：** 点击模组即可开启（应用会把它复制进游戏文件夹）。开启一个会关闭同**分类**里的其他模组。再次点击即可关闭。
- **模组状态：** 每个模组会显示 已开启、可用、缺文件 或 孤立。
- **编辑模组：** 右键 → **编辑**，修改名称、作者、分类、标签、分级与备注。
- **图片：** 设置封面图并管理模组的预览图。
- **更多（右键）：** 替换文件、修复、编辑按键、打包分享、合并、优化、删除。*（部分选项需要先开启模组。）*

## 分类

分类以文件夹树的形式整理你的库，也是执行“同时只开一个”规则的地方。右键树可添加、重命名、导出或删除分类；**拖拽**可重排。

## 标签与搜索

- **标签**是自由标注（编辑模组时添加），方便你按任意方式筛选库。
- **搜索**会检索名称、标签和 id。可组合关键词、用 `OR`、用 `-` 排除，或用 `"精确短语"` 搜索。

## 模组的按键与设置

许多皮肤用按键来开关部件或切换外观。**先开启模组**，再右键它：

- **按键：** 点击按键输入框并**按下**你想要的键（单键、组合键或手柄按键）。也可以改变按键行为（点按 / 长按 / 循环），并拖拽重排按键。
- **高级设置：** 模组自身选项的编辑器。安全的设置可编辑；技术性部分被锁定，避免你不小心弄坏模组。

## 修复模组

游戏更新后，模组可能不再显示，直到被“修复”。先添加一次你的修复工具（见配置），然后右键模组 → **修复**，或修复整个分类。应用会替你修好并保存。

## 合并模组

把同一角色的多个版本合并成一个用按键切换的模组。选中它们 → **合并** → 选择按键。原始模组原样保留。

> [!NOTE]
> 合并后请进入游戏，测试切换键是否按预期循环各外观。

## 优化模组

右键 → **优化**，为模组瘦身——删除重复文件以节省空间。

## 远程库

在应用内浏览模组站点，一键添加模组。内置站点包括 **Hui站** 与 **GameBanana**，也可以自行添加。

- **库：** 每个库是一个**站点 + 游戏**。添加后会下载其模组列表，让搜索与浏览即时可用。
- **找模组：** 按名称或标签搜索、按最新排序，或用**已下载**筛选只看你已拥有的。绿色 **✓** 标记已导入的模组。
- **下载：** 打开模组并选择一个下载。它会自动加入你的库——打好标签并归入分类。
- **快速跳转：** 已导入模组的页面上有**查看模组**按钮，直接带你到库中的它；模组详情里也有**查看来源页面**，可以跳回它的远程来源页。

## 预设

**预设**会记住你开启了哪些模组。保存当前搭配，之后加载它即可还原那套组合——方便在喜爱的外观之间切换。预设位于底部栏。

## 工具

- **分析** —— 检查模组问题并标记需要修复的。
- **文件清理** —— 删除残留文件以释放空间，包括远程库下载后残留的文件。
- **模组 ID 迁移** —— 对旧模组的一次性整理。
- **修复工具** —— 添加用于修复模组的工具的地方。

## 活动

耗时任务——开启模组、下载、同步、修复——都在后台运行，保持应用流畅。底部栏显示正在进行的任务；点击**活动**区域可查看进度、历史并取消。

# 配置

## 模组放在哪里（工作目录）

**设置 → 模组工作。** 这是应用放置模组、供游戏加载的位置：

- **应用默认** —— 由应用管理自己的文件夹。
- **XXMI 启动器** *（推荐）* —— 指向你的 XXMI 安装目录并选择所玩游戏的导入器。这会同时设置模组放置位置**和**游戏启动方式。
- **自定义文件夹** —— 你选择的任意 3DMigoto `Mods` 文件夹。

> [!TIP]
> 还没有安装 XXMI？选择器里提供**下载并安装 XXMI** —— 自动获取官方安装包并为你打开。安装完成后在这里选择安装目录即可。之后想更新 XXMI，点**打开 XXMI Launcher** —— 它自己的窗口会更新启动器和游戏导入器。

## 启动游戏

底部的**启动**按钮会带着已开启的模组启动游戏。若使用 XXMI，应用会替你填好启动命令。你可以在**设置 → 模组工作 → 游戏启动**查看或修改它。

## 内容遮罩

需要直播或共享屏幕？**设置 → 全局设置 → 内容遮罩** 会对应用内置检测器判定为敏感的预览图加模糊——覆盖远程库网格和模组预览面板。鼠标悬停、打开详情或使用全屏查看器即可查看。检测完全在本机进行，不会上传任何内容。

## 登录下载站点

有些站点需要先登录才能下载。在**设置 → 在线存储**点击**登录**——会弹出打开该站点**自己的登录页**的窗口。在那里登录（你不会在本应用中输入密码）。之后应用就能替你从该站点下载。

## 设置速查

- **模组工作** —— 模组放置位置 + 启动命令。
- **导入** —— 新模组的导入方式。
- **修复工具** —— 你的模组修复工具。
- **全局** —— 主题（明/暗）、语言（English/中文）、更新。
- **在线存储** —— 你在下载站点的登录。

# 关于

## 关于与帮助

D3dxSkinManager 免费且开源。在 GitHub 获取更新与反馈问题：
<https://github.com/JiarongGu/D3dxSkinManager>

它与 **XXMI** 协同工作——XXMI 才是真正把模组加载进游戏并启动它的那一环。本应用是你收藏、整理、修复模组的库与工作台。

**快速解决：**
- *某个模组看不到按键？* 先开启该模组。
- *修复或开启失败并提示“正被占用”？* 运行中的游戏正打开该文件——重试（应用也会自动短暂重试），或关闭游戏/在游戏内卸载该模组后再操作。否则借助 3DMigoto 热重载（F10）可保持游戏开启。
- *更新后模组不见了？* 工具 → 分析，然后修复。
- *下载失败？* 确认已登录（设置 → 在线存储）。
- 模组是部署到 Mods 文件夹、由 3DMigoto 加载的（游戏可用 F10 热重载）；唯一的限制是运行中的游戏当前正打开的文件无法被覆盖（会提示“正被占用”）。
