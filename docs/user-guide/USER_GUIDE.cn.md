# D3dxSkinManager — 使用指南

D3dxSkinManager 是面向 3DMigoto 类游戏（通过 XXMI）的**模组库管理器**：原神（GIMI）、绝区零（ZZMI）、崩坏：星穹铁道（SRMI）、鸣潮（WWMI）、崩坏3（HIMI）、终末地（EFMI）等。

它把模组**压缩存储**，让你**整理、修复、编辑、预览并部署**模组，而真正的游戏内注入交给 **XXMI**。可以这样理解：*本应用 = 你的模组库 + 工作台；XXMI = 把模组加载进游戏的运行时。*

本指南按**操作流程**组织——找到你要做的事对应的小节即可。第一次使用？按 1 → 3 的顺序读，这就是完整的基础循环（配置 → 添加模组 → 游玩）。

> **核心概念：** 模组以压缩形式存放在库中。**加载**模组会解压并部署到游戏的 Mods 文件夹；**卸载**则移除它。同一分类**同时只有一个模组生效**——加载某个模组会自动卸载同分类下先前加载的那个。

---

## 1. 首次配置

**目标：** 准备好一个配置文件和部署目标，让模组能加载、游戏能启动。

1. **创建或选择配置文件（Profile）** —— 点击右上角的**配置文件选择器**。每个配置文件都是独立工作区（模组数据库、分类、设置）。建议每个游戏用一个。
2. **打开 设置 → 模组工作**，选择**工作目录**——模组部署、供游戏加载的位置：
   - **应用默认** —— 由应用管理其内部文件夹。
   - **XXMI 启动器** *（推荐）* —— 指向你的 XXMI 安装目录，再选择导入器（如 `ZZMI`）。一步同时设置好部署目标（该导入器的 `Mods` 文件夹）**和**启动命令。
   - **自定义文件夹** —— 任意 3DMigoto 的 `Mods` 文件夹。
3. **确认。** 选择 XXMI 导入器时，会先弹出确认框展示工作目录、部署目标、启动器路径与启动参数，确认后才应用。

> 下一步：添加一些模组（第 2 节），然后加载并启动（第 3 节）。

---

## 2. 把模组加入库

**目标：** 把模组放进你的压缩库，以便整理和部署。

### 导入文件或文件夹
1. 把存档（`.zip` / `.7z` / `.rar`）或模组文件夹**拖拽**到窗口——或使用**导入**按钮。
2. **导入流程**会在模组进入库之前处理多模组存档、命名与分类归属。

### 导入分享的包
- 别人发给你一个**包（Package）**？用同样方式导入。你也可以把某个模组（或一组）**导出**为包来分享。

> 想从网站获取模组，见**第 8 节——从远程库下载**。
> 每个加入的模组都会被**规范化**为应用的存储格式（解压 + 重新压缩），因此奇怪的容器或密码不会在之后加载时出问题。

---

## 3. 加载模组并启动游戏

**目标：** 激活一个模组并在游戏里使用它。

1. 进入**模组**标签页。在左侧选一个**分类**，其模组显示在右侧。
2. **点击模组**即可**加载**——应用会解压并部署到工作目录。
3. 记住规则：加载某个模组会**卸载**同**分类**下的其他模组（同分类只有一个生效）。再次点击已加载的模组即可**卸载**。
4. 点击状态栏的**启动**按钮开始游戏。使用 XXMI 时，启动会注入模组 DLL 并以模组生效的方式打开游戏。

### 用预设保存搭配
- **预设**保存你当前已加载的模组集合。存一个，之后应用它即可精确还原那套组合——方便在多套精心搭配之间切换。预设位于头部/状态栏的**预设**。

---

## 4. 整理你的库

**目标：** 让庞大的库也能快速找到东西。

- **分类**（左侧树）：右键可 添加子分类、添加根分类、编辑、导出、删除；**拖拽**可重排或移动。每个模组属于一个分类（由此驱动“同分类只有一个生效”规则）。
- **标签：** 在模组的**编辑**界面添加自由标签；按标签筛选列表。远程导入的模组会自动带标签。
- **搜索：** 搜索框匹配标题、标签和 id，支持运算符——空格 = 与(AND)、`OR`、`NOT`/`-`、`字段:值`、`"精确短语"`。
- **编辑模组**（右键 → 编辑）：名称、作者、分类、标签、分级、描述。
- **预览：** 设置缩略图并管理模组的图片。

---

## 5. 自定义模组的按键与配置

**目标：** 修改模组的切换键或调整其设置。

1. **先加载模组**——快捷键和配置来自其解压后的文件（若某项灰显，就是这个原因）。
2. 右键 → **快捷键**。每个绑定你可以：
   - **重绑：** 聚焦输入框并**按下**目标键/组合来捕获（支持修饰键与 `NO_…` 排除；用 **Xbox 按键选择器**添加手柄按键）。
   - 更改**类型**（cycle / hold / toggle），编辑**循环值** / **条件**。
   - 给一个绑定添加**多个按键**，并**拖拽重排**绑定。
3. 需要更深入的调整，右键 → **`.ini` 编辑器**：编辑安全的 `键 = 值` 行（`[Key*]`、`[Constants]` 可调项）。哈希/覆盖段被**锁定**——改哈希会让模组失效。

---

## 6. 游戏更新后修复模组

**目标：** 游戏改动哈希后，让模组重新渲染。

1. **关闭游戏**（占用中的文件无法修改）。
2. 在**设置 → 修复工具**中添加一次你的修复工具。
3. 运行**工具 → 分析**，查看哪些模组损坏（错误/缺失哈希、冲突、缺失快捷键）——每个模组会得到健康徽标。
4. 右键模组 → **修复**（或一次**修复整个分类**）。修复会打补丁并自动重新保存其存档。
5. 重新运行分析或启动以确认。

---

## 7. 合并与精简模组

**目标：** 对库进行进阶编辑。

- **合并变体：** 选中若干同角色模组 → **合并** → 选一个在游戏内循环切换它们的**切换键**。会生成一个新的合并模组（原始保留）；它基于命名空间，因此每个变体保留自己的按键。*合并后请在游戏内实测切换键。*
- **优化：** 右键 → **优化**，去重相同文件并重写内部 `filename` 引用——整理臃肿的模组。

---

## 8. 从远程库下载模组

**目标：** 在应用内浏览模组站点并一键导入。内置来源：**Hui站（huihui）**与 **GameBanana**（还可添加自定义站点）。

1. **添加一个库。** 打开**库管理**（库管理）→ **库** → 添加一个 = **站点 + 游戏**（如 *GameBanana · 绝区零*）。添加后会启动后台**同步**，建立本地索引（即时搜索/排序/离线）。从工具栏下拉切换当前库。
2. **浏览与筛选。** 搜索匹配标题 + 标签；排序可按站点顺序或最新；**已下载**筛选只显示你已导入的。卡片显示标签徽标，已导入的显示绿色 **✓**。
3. **打开模组** → 详情页：左侧画廊 + 标签，右侧**下载链接**。
4. **下载并导入。** 点击某个链接：
   - **Cloudreve / 直链** → 在**应用内**下载并导入。
   - **夸克** → 在你登录后于应用内下载（第 9 节）。
   - 其他主机 → 在浏览器中打开。
   确认对话框（文件、大小、主机）；可选择**分类**（覆盖标签规则）与**解压密码**。下载 + 导入在后台运行——在**活动**面板查看。
5. **导入完成后**，模组进入你的库（已打标签并归类），条目显示 **✓ 已导入**。打开其详情 → **查看模组**即可跳转到库中的它。

### 导入标签规则（每个库）
每个库有一组**有序规则**，把远程标签映射到导入时的本地分类（首个匹配生效；无匹配 = 未分类）。在库管理 → 该库的**导入规则**标签页编辑。

---

## 9. 账号与设置

**目标：** 登录下载主机并调整应用。

- **夸克登录**（**设置 → 在线存储 → 登录**）：会弹出应用内窗口打开**夸克自己的登录页**——在那里登录（你不会在本应用中输入密码），会话会被自动捕获。之后应用会像官方桌面客户端一样下载你的夸克文件。
- **设置各标签页：**
  - **模组工作** —— 工作目录模式 + 游戏启动命令（路径 + 参数，如 `--nogui --xxmi ZZMI`；部分游戏需额外参数，如鸣潮 `-DisableModule=streamline -dx11 -d3d11`）。
  - **导入** —— 导入行为 / 默认值。
  - **修复工具** —— 修复工具库。
  - **全局** —— 主题（明/暗）、语言（English/中文）、日志级别、自动更新。
  - **在线存储** —— 下载主机账号。

---

## 10. 后台任务与活动

**目标：** 跟踪耗时操作。

加载、导入、同步、合并、修复、分析都在**后台**运行，保持应用流畅。**状态栏**显示运行中的概要；点击**活动**区域可打开完整面板——每个任务的进度、历史与取消。

---

## 11. 界面速查

- **顶部导航：** **模组** · **远程库** · **工具** · **设置**。
- **头部：** 配置文件选择器 · 本帮助。
- **底部状态栏：** **启动** · **预设** · 已加载模组数量 · **活动**。
- **模组卡片状态：** 已加载 · 可用 · 不可用 · 孤立。
- **主题与语言：** 设置 → 全局（明暗主题都支持）。

---

## 12. 故障排除

- **快捷键看起来是空的？** 先加载模组——它们来自解压后的文件。
- **提示“模组文件夹被占用”/ 修复或加载失败？** 先关闭游戏（游戏会占用文件）。
- **游戏更新后模组不显示了？** 运行**工具 → 分析**，再**修复**被标记的模组。
- **夸克下载失败？** 确认已登录（设置 → 在线存储）。超大文件会走桌面客户端路径下载；若某文件确实受限，请直接在夸克中下载。
- **放心试验：** 本应用的操作都不会注入到正在运行的游戏，因此在游戏关闭时加载/修复/部署都不会影响正在运行的游戏。
