# Rules Index

One-line-per-rule registry + router. **Read this first** for the mandatory rules check — this index is always-loaded, but **most rules are NOT** (see Loading model below), so this table is how you discover the on-demand ones.

**Each row is a pointer, not the rule.** "Enforces" is the single core invariant + enough to decide *should I open this file?*. The full contract — wiring chain, edge cases, examples — lives in the linked rule file. Keep rows to one line; do NOT paste rule bodies back into this table.

> **Loading model.** Only a tiny **core** of universal-workflow rules auto-loads every session — the bare-`*.md` rows (`skills-workflow`, `no-global-memory`, `scripts-live-in-repo`, `risky-change-tests-first`) plus this index and `TEMPLATE`. **Every other rule lives in `.claude/knowledge/` and is on-demand — its body is NOT in your context until you `Read` it.** So when a row links to `../knowledge/*.md` and its **Applies When** matches the task, **`Read` the linked file before acting** — otherwise you're flying blind on that contract. (This split keeps session base-context small; the always-loaded rules total ~15 KB instead of ~190 KB.)

## How to Use

1. Before any non-trivial task, scan the **Applies When** column for matches.
2. If a rule matches → **`Read` its full file** (`../knowledge/*.md` bodies are NOT in context; rules override generic knowledge).
3. New rule discovered (multi-file wiring chain, recurring correction) → **`node devtools/dev.mjs knowledge new <kebab-name>`** scaffolds `.claude/knowledge/<name>.md` from [TEMPLATE.md](TEMPLATE.md) (situational — the default) AND auto-appends its row here; fill in Applies-When + a one-line Enforces, then `node devtools/dev.mjs knowledge check`. Use `--core` only for a universal-workflow rule needed on *every* task.

## Invariants

- One rule file = one concern. No god-files.
- **Core stays tiny.** A new rule defaults to `.claude/knowledge/` (on-demand); the always-loaded `.claude/rules/` core is deliberately the 4 universal-workflow files + 2 meta. Don't grow it.
- **One row = one line.** The row is a pointer; the rule file holds the detail. If a row needs a paragraph, it belongs in the file, not here.
- Every rule row has a file that actually exists. Dead rows waste reader attention.
- Rule names are kebab-case and describe **what is enforced**, not the incident that caused them.
