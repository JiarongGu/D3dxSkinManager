### critical-1. Arbitrary script execution — scriptPath not confined to the fix-tools directory
- **Where:** `D3dxSkinManager/Modules/Tool/Services/ModFixService.cs:133-148`  (be-tool)
- **Category:** security  -  **Confidence:** 85  -  **Rule:** filesystem-operation-serialization.md — SECURITY invariant: EXTRACT-ONLY, NEVER EXECUTE; CLAUDE.md Section 2 — Backend must enforce input constraints
- RunFixAsync validates that the file exists and has a supported extension, but never checks that the path is actually inside {profile}/fixtools. The IPC payload field 'scriptPath' is a raw absolute path supplied by the caller. Any caller with IPC access can execute an arbitrary .py, .bat, .cmd, or .exe anywhere on the filesystem — e.g. C:\Windows\System32\cmd.exe or any user-accessible file. This is separate from the extract-only invariant (archives are never executed) — it is the script-runner path that is unguarded.

### high-7. Dual-completion race: API .then() and COMPLETED event both navigate to Complete and show notifications
